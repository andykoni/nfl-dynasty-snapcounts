NFL Dynasty Snap Dashboard — V1

Open index.html in a browser to preview the interactive dashboard.

This V1 is a visual/interaction prototype. The live version will replace data.json with the full current-roster + snap-count dataset and retain weekly history separately.

Planned live behaviour:
- MFL is the source of truth for current rosters.
- Add/drop/trade changes appear after the next scheduled refresh.
- Four leagues are configurable by season.
- Offense and IDP are separate units.
- Historical snap data is retained even when a player is no longer on the current roster.
- GitHub Pages hosts the dashboard.
- GitHub Actions refreshes the data automatically.
